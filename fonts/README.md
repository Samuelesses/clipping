# Bundled fonts

These fonts are burned into clip titles/captions via ffmpeg's `ass` filter
(`fontsdir`), so styling looks the same on every machine regardless of what
fonts happen to be installed locally.

- **Anton-Regular.ttf** - used for the title overlay.
- **Montserrat-ExtraBold.ttf** - used for the caption track.

Both are from [Google Fonts](https://fonts.google.com) and licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/), which permits
bundling/redistribution (including commercial use).
